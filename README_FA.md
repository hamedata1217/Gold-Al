# Gold AI — نسخه ساده قابل اجرا با آیفون

## نکته مهم درباره قیمت
این نسخه داده کندل نماد `XAUUSD=X` را از Yahoo Finance می‌گیرد. این داده، فید مستقیم MT5 یا Eplanet نیست و ممکن است با قیمت، اسپرد و زمان‌بندی بروکر اختلاف داشته باشد. تا وقتی API رسمی یا ترمینال MT5 واسط نداریم، نباید آن را قیمت قطعی بروکر فرض کنیم.

## فایل‌ها
- `bot.py`: ربات تلگرام و دستورها
- `market_data.py`: دریافت قیمت و کندل و تابع `get_candles(tf)`
- `indicators.py`: محاسبه EMA، MACD، RSI و ADX
- `strategy.py`: امتیازدهی و جمع‌بندی تایم‌فریم‌ها
- `requirements.txt`: کتابخانه‌ها
- `Procfile`: فرمان اجرای worker

## تنظیم Environment در هاست
این دو متغیر را در بخش Environment قرار بده:
- `TELEGRAM_BOT_TOKEN` = توکن ربات تلگرام از BotFather
- `ALLOWED_USER_IDS` = شناسه عددی تلگرام خودت (اختیاری؛ اگر خالی باشد همه می‌توانند دستور بدهند)

توکن را داخل فایل‌های GitHub ننویس.

## اجرا
نوع سرویس را Worker انتخاب کن و دستور اجرا را `python bot.py` قرار بده. سپس Deploy یا Redeploy کن.

## دستورهای تلگرام
- `/start`
- `/price`
- `/signal`
- `/help`

## محدودیت
Yahoo ممکن است داده 1 دقیقه‌ای را محدود کند یا موقتاً در دسترس نباشد. در آن صورت خطای دریافت داده نمایش داده می‌شود. این ربات سیگنال تضمینی یا توصیه سرمایه‌گذاری ارائه نمی‌کند.
